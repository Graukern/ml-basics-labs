# Влияние параметра C в SVC

## Цель работы

Проверить, как параметр `C` влияет на качество SVC при разных ядрах.
В качестве примера используются характеристики автомобилей.

## Данные

Используется локальный файл `src/car_dataset.csv`.
В нём 1500 автомобилей и их характеристики:

- объём двигателя;
- мощность;
- масса;
- длина;
- количество дверей и мест;
- расход топлива;
- возраст;
- пробег;
- цена.

Целевой признак — сегмент автомобиля: `city`, `family` или `sport`
(городской, семейный и спортивный).
Датасет сгенерирован программно с фиксированным seed, поэтому интернет для запуска не нужен.
Данные специально сделаны с некоторым перекрытием между сегментами, чтобы задача не была
идеальной и влияние `C` было видно на графиках.

## Что проверяется

- ядра `linear`, `rbf`, `poly` и `sigmoid`;
- значения `C` от `0.001` до `1000`;
- масштабирование признаков через `StandardScaler` внутри `Pipeline`;
- accuracy, balanced accuracy и macro F1;
- разница между качеством на обучении и валидации.

## Результаты

После запуска ноутбука лучшим вариантом оказался `rbf` с `C=1`.
На тестовой выборке получились такие результаты:

| Метрика | Значение |
|---|---:|
| Accuracy | 0.9173 |
| Balanced accuracy | 0.9173 |
| F1 macro | 0.9168 |

Большие значения `C` не всегда улучшают результат: модель начинает сильнее
подстраиваться под обучающие данные. Это видно по разнице между train и validation.

